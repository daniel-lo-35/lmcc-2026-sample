# 三步以內推箱子

為單箱推箱子任務構建監督微調數據，提交數據整理函數和 LoRA 訓練參數，使固定的 Qwen3-0.6B 輸出最短行動路線。

> 提交：JSONL + Python 函數 + 5 項參數
>
> 目標：根據地圖生成最短 UDLR 路線

tag: 輸入與輸出、JSONL 格式、提交函數、訓練參數、校驗與測試

## 01 任務輸入：一張單箱地圖

輸入為 `地圖:`、一個換行及逐行排列的網格。地圖為 **5 行、5 列**，各行等寬；只接受下表的半角字符，空地使用減號 `-`，不能使用空格。

| 字符 | 含義 |
| --- | --- |
| # | 牆，玩家與箱子均不能進入。 |
| - | 空地。 |
| @ | 站在普通地面上的玩家。 |
| $ | 位於普通地面上的箱子。 |
| . | 箱子的目標位置。 |
| + | 站在目標位置上的玩家，同時表示一個玩家和一個目標。 |
| * | 位於目標上的箱子，同時表示一個箱子和一個目標。 |

每張地圖需恰好有 **1 個玩家、1個箱子、1個目標，** 組合字符按對應實體計數。地圖邊界不能越過。

```user.content - 示例地圖
地圖:
#####
#.--#
#$-##
#@--#
#####
```

## 02 行動規則與輸出格式

- `U / D / L / R` 分別表示玩家向上、下、左、右移動一格，走路和推箱子都計 1 步。
- 前方是箱子時，僅當箱子再前方的格子在地圖內且不是牆，才能將箱子推一格；玩家進入箱子原位置。不能拉箱子、穿牆或越界。
- 只有箱子需要達到目標，玩家不需要到達目標；到達後結束。答案必須是合法的最短路線，存在多個等長最短解時均可使用。
- 本卷5個測試地圖的最短路徑為 1-3步；你提交的訓練地圖可覆蓋 1-30步，必須有解。初始箱子已在目標上的零步地圖不在本次訓練接收範圍。

示例地圖的正確答案是`U`。訓練數據中的 `assistant.content` 推薦只寫路線；也允許 `<think>思考內容</think>` 後接路線，校驗最終路線是否為 1-30 位大寫 UDLR、合法且最短。

**測試最終輸出**只能是連續大寫 UDLR。額外的空格、換行、標點、解釋或思考標籤均判失敗，不會自動去除。

## 03 訓練數據：JSONL 格式

`dataset` 是 UTF-8文本。每個非空物理行是一條完整 JSON 對象，共 **2-100條；** 不要在外層套數組，也不要提交 Markdown 代碼圍欄。JSON字符串裡的換行要寫成 `\n`，不能把一條JSON拆成多行。

| 字段 | 類型 | 要求 |
| --- | --- | --- |
| `messages` | 數組 | 恰好 3 條，順序固定為 system、user、assistant。 |
| `messages[0].content` | 字符串 | system 提示，僅作訓練數據使用。 |
| `messages[1].content` | 字符串 | 地圖，格式 `地圖:` + 一個換行 + 逐行網格（冒號後不加空格）。 |
| `messages[2].content` | 字符串 | 該地圖的正確答案：1-30 位大寫 UDLR，可前置 `<think>…</think>`。 |

訓練樣本中的 `system.content` 僅作為訓練數據使用；他不會替換測試階段的固定指令。

### 可直接提交的完整 JSONL

下方為完整訓練樣例。

```dataset.jsonl - 1條完整樣例
{"messages":[{"role":"system","content":"求解單箱推箱子，只寫最短 UDLR 動作串，箱子到目標即結束。"},
{"role":"user","content":"地圖:\n#####\n#.--#\n#$-##\n#@--#\n#####"},{"role":"assistant","content":"U"}]}
```

## 05 訓練參數

返回的 `params` 必須完整包含下列五個鍵，名稱區分大小寫，不接受額外參數。所有值均為數值，不要寫成字符串。

| 字段 | 含義 | 允許值 | 默認值 |
| --- | --- | --- | --- |
| epochs | 遍歷訓練集的輪數。 | 整數 1-20 | 8 |
| learningRate | 優化器學習率。 | 數值 0.00001-0.001，含兩端 | 0.0003 |
| loraRank | LoRA 適配器的秩。 | 4, 8, 16, 32 | 16 |
| batchSize | 每次前向計算的樣本數。 | 1, 2, 4 | 1 |
| gradAccum | 一次參數更新前累積的批次數。 | 1, 2, 4, 8, 16 | 8 |

例如 `batchSize=1`、`gradAccum=8` 表示累積8個批次後再更新一次參數。模型固定為 Qwen3-0.6B，訓練方式固定為 LoRA。

### 固定訓練設置

完整程序使用 `torch`、`transformers` 和 `peft`。僅 assistant 的 token 參與損失；單條樣本最多 **4096 token**，超長時提示錯誤，不自動截斷。隨機種子為 `2026`。

LoRA 作用於 `q_proj / k_proj / v_proj / o_proj / gate_proj / up_proj / down_proj`，`alpha = 2 * rank`、`dropout = 0.05`；優化器為 AdamW，權重衰減 `0.01`，梯度裁減上限 `1.0`。訓練完成後保存適配器、分詞器與訓練紀錄。

- **測試固定指令**（只讀，評測時作為 system）：

```
你是單箱推箱子求解器。地圖符號：#牆，-空地，@玩家，$箱子，.目標，+玩家在目標上，*箱子在目標上。U/D/L/R 表示玩家向上/下/左/右走一格；走向箱子時把箱子推前一格，牆和邊界不能進入，箱子不能被推入牆或出界。只輸出把箱子推到目標的最短路線，由連續大寫 U D L R 組成，不要空格、換行、標點或解釋。
```

- **數據校驗**：每行須恰好 3 條 messages；地圖須滿足第 01 節全部限制；路線須合法且為最短；零步地圖與無解地圖報錯；同一地圖不得重複；不得把公開測試地圖加入訓練集。
- **`build_training_submission` 返回值**：`{"dataset": JSONL 文本, "params": 五項參數字典}`，`params` 不得多鍵或少鍵，數值類型須為數值（epochs 等為整數）。
- **測試判分**：每個測試點生成一次，輸出原樣匹配 `[UDLR]{1,30}`（不去空白），路線合法、把箱子推到目標且長度等於最短步數才算對。公開 5 點，隱藏 5 點；每點分值待定。
- 三步題中地圖不會出現 `+`（玩家站在目標上時至少需 4 步）和 `*`（零步）。
